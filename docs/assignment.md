# Разбор ТЗ и критерии приёмки

**Пользователь** ведёт личный блокнот на телефоне. Одна запись может относиться сразу к нескольким темам. Приложение должно работать без аккаунта и подключения к сети.

| История пользователя | Критерий приёмки |
| --- | --- |
| Хочу быстро записать мысль | Новая запись с заголовком или текстом сохраняется и отображается первой. Пустую запись сохранить нельзя. |
| Хочу исправлять и удалять записи | После изменения карточка обновляется. Удаление требует подтверждения. «Отмена» сохраняет запись. |
| Хочу собрать записи по теме | Тег выбирается из списка. Совпадение тега точное. Повторное нажатие снимает фильтр. |
| Помню только часть фразы | Поиск находит подстроку в заголовке, тексте и тегах без учёта регистра. Включённый фильтр сохраняется. |
| Хочу читать вечером | В настройках доступны системная, светлая и тёмная темы. Выбор сохраняется после перезапуска. |
| Хочу сохранить копию | Системный диалог предлагает файл Markdown. После записи в нём есть текст и теги всех заметок, включая скрытые фильтром. |

## Очерёдность работ

1. Спроектировать список, редактор и настройки. Связать каждый экран с пользовательской историей.
2. Описать модель записи и таблицу Room. Провести запись от формы до сохранения и повторного чтения.
3. Добавить поиск, фильтр, нормализацию тегов, оформление и экспорт UTF-8.
4. Проверить пустой блокнот, пустую выдачу, подтверждение удаления, обработку ошибок и повторное открытие.
5. Собрать подписанный APK, запустить модульные проверки и демонстрацию на эмуляторе.

## Макеты

В папке `wireframes` находятся три SVG с текстом и векторными слоями. Перетащите файлы на холст Figma Design. В проекте исходный макет описывает состав и порядок элементов. Финальные экраны приложения показаны в README.

## Границы версии

Локальное хранение в закрытом каталоге приложения. Экспорт охватывает весь блокнот. Импорт и облачная синхронизация в эту версию не входят.
